# B135.74 — PROFILE / CLEAN

B135.74 part de B135.71 afin de conserver l'oracle fonctionnel du duel et le
safety net `DAT_8009C4B8`.

## But

Compiler hors du build CLEAN les diagnostics potentiellement coûteux :

- timers GP0 ;
- compteurs raster/pixel ;
- scans DMA ;
- probes objets/VRAM ;
- gros blocs console.

`make` produit CLEAN, `make profile` produit PROFILE avec répertoires
d'objets séparés.

## Résultat du test

**Aucun gain FPS observable.**

Conclusion : l'instrumentation retirée par B135.74 n'est pas la cause principale
des ~12–15 FPS du duel. Le mode CLEAN reste utile pour mesurer proprement, mais
cette piste ne doit plus être considérée comme l'optimisation dominante.

B135.71 reste conservé comme référence fonctionnelle.
