# B135.76 → B135.80 — enquête rendu dialogue

Dernière mise à jour : **25 septembre 2026**.

## Symptôme

Après un duel, puis également au premier villageois sur une nouvelle partie :

- logique du jeu active ;
- appuis sur B capables de faire progresser ;
- personnage/texte absents ;
- écran ou backbuffer incorrect selon révision.

## B135.76 — presenter

Correction de deux problèmes :

1. B135.44 utilisait `fm_gpu_b127_perf_snapshot()` pour lire des champs draw
   que ce getter ne remplissait pas ;
2. Y=256 n'était pas correctement suivi dans plusieurs heuristiques.

La capture a ensuite montré une incohérence :

```text
PRES gp1:0,0 latch:320,0 draw:0,0
```

## B135.77 — draw-page priority

Tentative : faire passer E3/E4 devant l'heuristique de densité VRAM.

Résultat : **écran noir**.

Cause conceptuelle : la draw-page peut être le backbuffer en construction ; elle
ne doit pas être présentée automatiquement.

## B135.78 — arbitration conservatrice

GP1 est autoritaire sur les changements réels. Le suivi draw-page n'est admis que
dans un stale-GP1 prouvé.

Capture :

```text
PRES g:0,0 l:0,0 d:0,0 p:0 nz:0/0
```

Le presenter choisit donc une page cohérente, mais la page reste vide.

## B135.79 — objets / walkers / GPU

Nouvelles lignes :

```text
OBJ79 ...
WALK79 ...
GP2D79 ...
```

Capture déterminante :

```text
OBJ79 n:0/5/0/0/0/0/0
WALK79 ... 408bc:0 ...
GP2D79 rect/q/2c/3a:0/0/0/0
```

Ghidra confirme que :

- C2 = `DAT_800F11C2` ;
- `FUN_800408BC` parcourt C2 ;
- `FUN_80041674` parcourt C0..CC avec une table de 7 renderers ;
- la table est située à `0x800923DC..0x800923F4` ;
- C2 correspond au slot `0x800923E0`.

Conclusion : les objets du dialogue existent mais leur renderer n'est pas appelé.

## B135.80 — test discriminant

Branche :

```text
diag/b135.80-c2-indirect
```

Lignes attendues :

```text
TAB80 c0/c2/c4/cc:...
C2TAB h:... ptr:........ exp:800408BC ent:... r416:...
```

Décision :

- ptr C2 incorrect → réparer la table / chargement ;
- ptr correct, ent=0 → ajouter la fonction au dispatcher généré ;
- ptr correct, ent=1, 408BC=0 → corriger l'appel indirect/JALR ;
- 408BC>0, GPU 0 → instrumenter l'intérieur de 408BC et `800424B8`.

## Règle

Ne plus modifier le presenter avant d'avoir exécuté ce test.
