# B135.86 — chaîne réelle du texte de dialogue

Les captures B135.85 prouvent que la catégorie 2 est créée, dessinable et
parcourue pendant le portrait sans texte. Son appelant `8003748C` crée la
flèche de dialogue. Le chemin du texte, identifié dans l'export Ghidra, est :

`800393B8` lit le script → `800391EC` installe l'objet en catégorie 6 →
`80036C64` ajoute un caractère à la liste → `80041048` parcourt la catégorie
6 → callback `80036298` fabrique les primitives de glyphes.

Cette branche ne change pas le comportement du jeu. Elle compte les entrées
recompilées (`gen`) et interprétées (`outer`) de ces cinq fonctions, plus les
créations et suppressions de catégorie 6. Elle lit les quatre contextes de
texte `800F0850 + slot*100`, l'identifiant du script, les flags, l'état, le
pointeur d'objet et l'avancement du tampon de glyphes. Les compteurs sont
cumulés depuis le lancement ; `slot0..3` et `obj6` sont des instantanés.

```sh
git fetch origin
git switch diag/b135.86-text-path
git pull --ff-only
cd 3ds
make clean
make profile -j4
```

Lancer `fm-new3ds-profile.3dsx`. Photographier les deux écrans pendant le
portrait avec le cadre vide, puis quelques secondes plus tard ou après une
pression de B. La bande `B135.86 SCRIPT / GLYPH DIAG` est replacée en haut
de l'écran inférieur.

Lecture décisive :

- `script tick > 0`, `setup = 0` : le script est parcouru mais sa phase
  d'initialisation de l'objet texte n'est pas atteinte. Vérifier les flags et
  états des slots, notamment `0x4000`.
- `setup > 0`, `cat6 create = 0` : vérifier l'allocateur et le dispatch de
  `800403D0(a1=6)` ; distinguer `gen` et `outer`.
- `cat6 create > 0`, `head6=-1` : l'objet a été supprimé ou la liste est
  incohérente ; comparer `remove`, l'index et l'adresse de retour.
- `head6>=0`, `char=0` : le script ne remplit pas la liste des caractères.
- `char>0`, `draw=0` : objet de catégorie 6, flags ou callback à examiner.
- `draw>0` avec cadre vide : inspecter les primitives de glyphes, leur
  texture/CLUT et la page vidéo. Les compteurs GP0 globaux seuls ne prouvent
  pas que les glyphes sont visibles.

Les contrôles locaux `validate_main_c.py` et 35 tests Python passent. Aucun
SDK 3DS ni disque de jeu n'est disponible ici pour le test sur émulateur.
