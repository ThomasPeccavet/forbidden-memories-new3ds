# B135.75 — Interpreter Fast Path

B135.75 cible le fallback R3000A après l'absence de gain de B135.74.

## Modifications

- chunk hot-region : 256 → 2048 instructions ;
- limite externe : 256 → 32 ;
- plafond total inchangé : 65536 instructions ;
- accès RAM 16/32 bits simplifiés ;
- écriture redondante de `gpr[0]` supprimée.

## Résultat du test

**Pas d'amélioration visible.**

Conclusion : l'overhead de retour par chunk et ces micro-optimisations mémoire ne
suffisent pas à expliquer la lenteur du duel. Ne pas pousser davantage cette
piste sans profiler séparément code ARM, fallback, rasterisation et waits.

Aucun correctif de duel B135.64/B135.66/B135.71 n'était volontairement modifié.
