# B135.84 — parcours de la couche active du dialogue

Les photos B135.83 du premier personnage montrent le portrait, le cadre et la
flèche sans texte. La création C2 reste à zéro. La tête de la liste de catégorie
2 vaut `2` sur la photo avec le portrait. Cette branche suit donc le parcours
`80041674 → 80040B48 → 800418C0 → 800424B8` sans supposer que cette liste
contient à elle seule les caractères. Elle ne modifie pas le jeu ni le GPU.

```sh
git fetch origin
git switch diag/b135.84-dialogue-layer
git pull --ff-only
cd 3ds
make clean
make profile -j4
```

Lancer `fm-new3ds-profile.3dsx`, afficher le premier dialogue avec le portrait,
puis photographier les deux écrans. Garder la scène affichée quelques secondes
et prendre une seconde photo. Les valeurs `gen` et `outer` sont cumulées depuis
le lancement ; `head`, `nodes` et `textbox bright` sont des instantanés.

| Mesure | Ce qu'elle sépare |
| --- | --- |
| `cat2 gen/live/outer` et `compiled` | Entrée recompilée et dispatcher externe de `80040B48`, avec une tête de liste valide ou non. Une valeur `gen=0` ne prouve pas une absence d'exécution si `outer>0`. |
| `cat2 head`, `nodes/draw/tail` | Chaîne d'objets catégorie 2, indicateurs `0xC0` requis pour dessiner et boucle/index invalide éventuels. |
| `cat2 cb`, `flags`, `wh`, `raw14/1C` | État du premier objet vu à l'entrée du parcours, pour identifier son callback et ses données brutes sans interprétation prématurée. |
| `draw gen/outer/prim` | Entrées dans `800418C0` et `800424B8`; les appels peuvent provenir d'autres catégories et sont cumulatifs. |
| `GP0 rect/quad` | Commandes GPU globales, à comparer entre les deux photos. |
| `textbox bright page0/1` | Nombre de pixels RGB555 clairs dans l'intérieur du dialogue (`x=32..287`, `y=170..223`, un pixel sur quatre) sur les deux pages `x=0/320` à partir du `display_y` actuel. Ce n'est pas un compteur de glyphes : le décor ou le cadre peuvent contribuer. |

Si la liste est dessinable et le parcours actif mais le texte est absent, ces
mesures orienteront la prochaine inspection vers les primitives, textures et
page vidéo. Si la liste n'est pas dessinable, le callback et les indicateurs
permettront de remonter l'état de scène. La catégorie 2 peut ne concerner que
le cadre ou le portrait : on ne conclura pas qu'elle est la police sans preuve.

Contrôles locaux : `python3 tools/validate_main_c.py` et
`python3 -m unittest discover -s tests`.
Le SDK devkitARM et l'image du disque ne sont pas disponibles ici ; le test
3DS final dépend du build et de la capture sur Azahar/Citra.
